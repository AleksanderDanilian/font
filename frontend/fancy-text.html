How does this work?

These aren't fonts in the usual sense. Each letter is swapped for a different Unicode character that happens to look like a styled version of it — 𝐇 isn't "H in a bold font", it's its own character. That's exactly why it survives copy & paste anywhere: the app you paste into doesn't need to know any font, it just sees ordinary characters.

The trade-off is that only a fixed set of styles exists in Unicode, and some apps filter out certain characters. If a style shows up as empty boxes somewhere, that platform doesn't support those particular symbols — try another style.
